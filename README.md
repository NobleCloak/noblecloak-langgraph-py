# noblecloak-langgraph-py

Approvals for LangGraph (Python): decide, pause, verify, resume. The Python counterpart of
[`noblecloak-langgraph-ts`](https://github.com/NobleCloak/noblecloak-langgraph-ts), against the same `/v1`
module API contract.

**Status:** reserved. The `0.0.0` release on PyPI holds the name and contains no code; the adapter is built when its brief is dispatched.
